## 浏览器操作

使用本机 Edge 无头浏览器访问隔离的实际服务，演示数据与测试账本保存在工作目录，未写入用户正式账本。

- 加载研究工具，显示1000条合成行情与实际截止日，90根K线。
- 切换 RSI / KDJ / 布林 / MACD 曲线，图表正常显示。
- 新增自选及参考成本，触发一条规则；再次扫描新增0条。
- 启用并关闭30秒后台检查，看到实际检查时间。
- 扫描3个本地数据集，展开六条件明细；本次没有满足全部条件的样本，页面如实显示0。
- 较早记录日模拟买入10份；同日卖出被拒绝；下一记录日卖出5份后剩余5份。
- 修改单标的模拟仓位上限并保存。
- 检查920与390像素宽度，无页面级横向溢出；返回旧预测页面仍可读取报告。

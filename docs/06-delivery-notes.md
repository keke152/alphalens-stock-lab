# 交付说明与示例运行记录

## 交付内容

- 完整 Python 源码、浏览器界面、固定版本依赖与 Windows 启动脚本。
- 三份虚构 OHLCV 日线，每份 1000 行，位于 `data/`。
- 中文项目说明、模型架构、回测公式、API、面试讲解和扩展路线。
- `examples/demo-report.json`：随机森林分类和回归产生的完整结果；首次启动时作为看板默认报告。
- `examples/logistic-report.json`：相同数据和配置下的逻辑回归 / Ridge 结果。
- `examples/logistic-model.joblib`：真实拟合后的分类器、回归器、特征名、配置和时间划分，可用于学习模型持久化。
- Dockerfile、Compose 与 macOS / Linux 脚本作为可选启动方式。

源码 ZIP 不含虚拟环境、缓存或个人运行数据。首次启动需联网安装依赖；安装后默认数据、模型训练和主界面均在本机运行。Swagger 接口文档使用其默认在线静态资源。

## 实际完成的运行

本次在 Windows、Python 3.10 环境安装依赖，生成三组 CSV，实际执行两种模型训练并输出以下示例报告，随后启动 FastAPI 服务。下面展示的是固定合成数据上的计算记录。

共同条件：`DEMO.A`、1000 行、种子 42、入场阈值 0.55、每边手续费 5 bps、每边滑点 2 bps、初始资金 100000。测试期 195 个日内收益样本。

| 指标 | 随机森林 | 逻辑回归 / Ridge |
| --- | ---: | ---: |
| 方向准确率（分类阈值 0.5） | 55.90% | 58.46% |
| AUC | 0.586 | 0.612 |
| 模拟交易次数 | 41 | 23 |
| 含成本策略累计收益 | 10.95% | 2.71% |
| 最大回撤 | -3.59% | -3.98% |
| 同口径日内基准收益 | -29.51% | -29.51% |

这些数字来自 `examples/` 报告，没有连接真实行情，不能作为真实证券的预测效果或投资业绩。两种模型方向准确率与策略收益的排序不同，也说明不能只按准确率评价交易策略。更换数据或参数后结果会变化。

当前未添加或执行自动化测试；没有在 Docker、macOS 或 Linux 环境运行。启动成功与示例训练完成不代表所有边界输入和部署环境均已验证。

## 带去面试的操作

1. 在自己带去的电脑上解压项目，安装 Python 3.10 或 3.11，双击 `start.bat` 完成首次依赖安装。
2. 保留整个项目目录。演示时保持启动窗口打开，并访问 `http://127.0.0.1:8010`。
3. 先说明默认行情为合成数据，然后依次展示时间划分、预测、资金曲线和逐日记录。
4. 切换模型后点击“训练并回测”，展示完整计算链路与历史实验记录。
5. 遇到“实际股票怎么用”的提问，说明 CSV 接入、复权、交易规则与样本外评估的适配工作。普通 A 股 T+1 股票需要改变当前日内执行模型。

不要直接双击 `static/index.html`：界面依赖同源的 Python API，必须通过启动脚本提供的 HTTP 地址打开。

# v1.1：界面与研究功能更新

本次更新将背景调整为浅灰蓝色，并增加行情阅读、回测复盘和实验比较功能。Python 模型、特征、时间划分和原有回测计算方式保持一致。

## 1. 这个项目预测什么

模型用某条日线收盘时已经知道的数据，估计**下一条行情记录的开盘到收盘方向与收益**。日线连续时，下一条记录就是下一交易日。它没有预测下一日完整价格路径，也不直接预测下一日收盘价相对今日收盘价的变化。

默认数据是可复现的合成行情，可以改为导入自己的单标的 OHLCV CSV。行情不会实时更新，下一条记录的日期也不能由模型保证。模型分数和历史回测均不保证未来走势。

## 2. 行情区间与均线

打开研究概览，在行情图上切换 **30 / 90 / 250 日**，勾选或关闭“显示 MA5 / MA20”可同时控制两条均线。

- 图中“日”按行情记录条数计数，不是自然日。
- MA5 / MA20 为最近 5 / 20 条收盘价的简单平均。
- 均线先在报告已有的最多 250 条行情上计算，再截取显示区间；切换 30 日视图不会把均线历史重新从第 1 天开始计算。
- 可用历史不足 5 / 20 条时，均线留空。250 日视图开头可能因此没有均线。

这些操作只改变显示范围，不会重训模型，也不会改变回测结果。

## 3. 回撤与月度收益

进入策略回测，查看已有样本外结果的净值、回撤曲线和月度复利收益。

**回撤**表示当前策略净值相对截至当日历史最高净值的下降比例，起始资金参与历史峰值计算：

```text
回撤 = 当日策略净值 / 截至当日的最高策略净值 - 1
```

**月度收益**按测试集交易记录的月份分组，将已有的每日净收益复利累计：

```text
月度收益 = ∏(1 + 当月各条记录的净收益) - 1
```

策略收益已经包含原报告的交易成本；空仓记录的策略收益为 0。基准仍是每天开盘买入、收盘卖出并扣除同口径成本。测试集首月和末月可能只有部分日期，不能理解为完整自然月表现。这些图表复用已有报告，不会触发新的训练。

## 4. 筛选与导出预测记录

在预测记录区域设置交易日期起止范围，选择“全部 / 入场 / 空仓”以及“全部 / 判断正确 / 判断偏差”。筛选条件会同时生效。

点击筛选记录的 CSV 导出按钮，导出符合条件的全部记录，而不只是当前分页。没有匹配记录时应先调整筛选条件。

注意两个阈值的含义：

| 字段 | 判定口径 |
| --- | --- |
| 入场 / 空仓 | 上涨分数是否达到本次实验配置的入场阈值 |
| 判断正误 | 以 0.5 为方向分类阈值，与实际开盘到收盘收益是否大于 0 比较 |

“判断正确”不等于本次交易盈利：方向判定与入场阈值可能不同，且交易成本会影响净收益。空仓记录也保留方向判断，便于分析模型。

## 5. 两模型与历史实验对比

### 一键运行两种模型

1. 选择数据集并配置入场阈值、手续费、滑点、初始资金和随机种子。
2. 点击“一键双模型对比”，分别提交随机森林和逻辑回归实验。
3. 等待两次实验完成，页面会打开对比区；也可以手动选择历史实验。若某次任务失败，查看实验记录并重新运行。

这两个实验使用同一组数据和参数，只改变模型选择；沿用现有 `/api/runs` 接口，分别生成可回看的独立记录。

### 对比已有实验

选择两次已经完成的实验，可并列查看指标及参数。净值对比需要同时满足：

- 报告的 `dataset_sha256` 一致，即使用相同内容的数据；
- 实际测试交易日期序列一致。

满足条件时，两条策略净值分别除以各自的初始资金，以 **1** 为共同起点比较。不同初始资金因此不会使曲线仅因金额大小产生差别。

数据或测试日期不一致时，不绘制合并净值曲线。即使允许并列查看指标，也应结合数据范围、成本、入场阈值等参数理解差异。两模型比较展示的是一次既定留出集上的结果，不是长期优劣结论。

## 6. 修改参数后的提示

修改模型、阈值等研究参数后，已经显示的图表和指标仍属于之前的报告，页面会提示旧报告状态；只有新实验完成并打开后，结果才对应新参数。切换数据集会清空当前报告视图，避免误读。切换图表区间、均线或记录筛选只影响显示，不改变实验参数。

## 7. 更新范围与验证说明

修复了 Windows 将 `.js` 文件映射为普通文本时浏览器拒绝执行脚本的问题。服务现在显式返回正确的 JavaScript / CSS 类型，并保留 `nosniff`。滑杆增加了拖动区域与数值同步；原先“行情正在加载”和阈值读数不更新可能由这个静态资源问题同时引起。

本次增加展示、筛选、CSV 导出和对比交互；未增加实时行情、券商交易、模型自动调参或新的交易规则。默认合成数据、未经校准的上涨分数、日内开平仓假设等边界仍适用。

本说明记录功能与计算口径，不是自动化测试报告；没有在本文声称完成自动化测试。运行环境、依赖和启动方式见 [项目 README](../README.md)。

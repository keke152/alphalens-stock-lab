# AlphaLens 使用手册

一个可在本地演示的机器学习量化研究项目：导入日线行情，训练模型，预测下一条行情记录的**开盘到收盘涨跌方向与收益**，查看时间顺序留出集上的表现，并保存、比较和导出实验结果。正常连续日线中，下一条记录对应下一交易日；CSV 中的缺失交易日不会自动补齐。

**适合用途：** AI / Python / 数据开发岗位面试、机器学习课程项目、时间序列研究原型。默认展示可复现的虚构行情；不需要行情账号、付费模型或 API Key。

> 本项目是研究演示。模型输出和历史回测不代表未来收益。当前执行假设为“次日开盘买入、当日收盘卖出”，不能直接用于实行 T+1 的 A 股普通股票现货交易。

## 1. 能演示什么

| 功能 | 演示内容 |
| --- | --- |
| 行情研究 | 3 组固定种子的虚构日线数据；支持导入单标的真实行情 CSV；30 / 90 / 250 日视图与 MA5 / MA20 均线 |
| 真实机器学习 | 分类模型输出上涨分数，回归模型输出下一日开盘到收盘收益估计 |
| 时间顺序评估 | 按时间划分训练、验证、测试数据，在边界留出隔离行 |
| 策略研究 | 自定义上涨分数阈值、手续费与滑点，比较策略和同口径基准 |
| 可解释展示 | 浅灰蓝界面；价格、净值、回撤曲线、按月复利收益、分类与回归指标、特征贡献展示 |
| 预测复盘 | 按交易日期、入场 / 空仓、判断正误筛选样本外记录，并导出筛选后的 CSV |
| 实验管理 | 本地 SQLite 保存实验；一键运行两种模型；选择两次完成实验比较指标及符合条件的归一化净值 |
| 工程交付 | FastAPI 后端、浏览器界面、一键启动脚本、接口说明和面试讲解文档 |

所有绩效数字均由报告记录的数据与参数计算。修改参数后，页面会提示当前仍是旧报告，需要重新运行才能更新结果。默认样本中的名称、价格、交易日期和收益均为演示数据；没有实时行情连接、交易账户或自动下单功能。

本次界面与研究功能更新的操作说明见 [v1.1 更新说明](07-v1.1-update.md)。

从旧版升级时，请先获取当前仓库的最新源码。升级时保留原 `runtime/`（行情、报告和实验记录）与 `.venv/`；关闭旧服务后，用新包中的源码覆盖项目文件，再重新启动。仓库源码不含个人运行数据，不能代替 `runtime/` 备份。

## 2. Windows 快速启动

### 第一次启动

1. 安装 **Python 3.10 或 3.11**，安装时勾选 “Add Python to PATH”。这两个版本适合项目固定的依赖版本。
2. 将项目完整解压到一个可写的文件夹。
3. 双击项目根目录的 **`start.bat`**。
4. 首次运行会创建项目内的 `.venv` 并安装 `requirements.txt` 中的依赖，需要访问 Python 包下载源。
5. 浏览器打开 **<http://127.0.0.1:8010>**。

保持启动窗口打开，关闭服务时在该窗口按 `Ctrl+C`。依赖安装完成后，使用内置行情进行演示不需要连接外部 AI 或行情服务。

### 命令行启动

在项目根目录打开 PowerShell：

```powershell
.\start.ps1
```

如果设备的 PowerShell 策略不允许直接执行脚本，使用 `start.bat`。也可手动启动：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

如果安装的是其他 Python 3.10+ 版本，将创建环境命令中的 `py -3.10` 换成对应的解释器，例如 `python`。macOS / Linux 用户可使用 `python3 -m venv .venv`，后续解释器路径改为 `.venv/bin/python`。

交互式接口文档：<http://127.0.0.1:8010/docs>。

macOS / Linux 可执行 `sh start.sh --no-browser`；Docker 用户可执行 `docker compose up --build`，随后访问同一地址。Docker 数据保存在命名卷中。以上是可选启动方式，本次在 Windows Python 3.10 环境运行。

PowerShell 自定义端口：`powershell -ExecutionPolicy Bypass -File .\start.ps1 -Port 8011`。

## 3. 面试前 5 分钟操作

1. 打开页面，选择一组内置虚构行情，指出页面的数据来源标识。
2. 保持默认模型与成本参数，运行一次研究，讲解训练、验证、测试的时间边界。
3. 先解释预测目标：使用当天收盘已知的信息，研究下一条行情记录的**开盘至收盘**收益；切换行情区间和 MA5 / MA20 展示历史价格。
4. 查看测试集准确率、净值、回撤曲线和月度复利收益；展示策略与“每天开盘买入、收盘卖出”的基准。
5. 使用两模型运行功能，在相同数据与参数下分别训练随机森林和逻辑回归，再选择两次完成实验对比。
6. 按交易日期、入场 / 空仓、判断正误筛选预测记录并导出 CSV，解释预测判断与实际交易收益的区别。
7. 修改信号阈值或成本参数，观察旧报告提示；重新运行后再查看对应结果。

更完整的逐分钟讲稿见 [演示与面试讲解](04-demo-and-interview.md)。不要为了好看的结果反复调整测试集上的参数；正式研究需要重新保留未看过的数据。

## 4. 导入自己的行情

上传 UTF-8 或 GB18030 编码的 CSV，包含下列字段：

```csv
date,open,high,low,close,volume
2024-01-02,10.00,10.35,9.90,10.20,1250000
2024-01-03,10.18,10.50,10.10,10.42,1380000
```

上面两行仅用于解释格式，实际导入需 **300–20,000 行**。每个文件只能包含一个标的，日期不重复，价格为正，成交量非负，最高价和最低价应覆盖开盘、收盘价格。缺失值、异常数字和 OHLC 关系错误应先修复。请统一复权口径，不能将未复权开盘价与复权收盘价混用。

推荐先使用已有授权的数据源导出日线，再在本地导入。项目不会自动爬取证券网站。详细口径见 [数据与回测说明](02-data-and-backtest.md)。

## 5. 项目目录

```text
alphalens-stock-lab/
├─ app/                  Python 服务与研究计算
├─ static/               浏览器界面、交互与图表
├─ data/                 演示数据与 CSV 示例
├─ examples/             两种模型真实计算的示例报告、逻辑回归模型文件
├─ docs/                 中文项目文档
├─ requirements.txt      Python 依赖
├─ start.bat             Windows 双击入口
├─ start.ps1             PowerShell 启动脚本
├─ start.sh              macOS / Linux 启动入口
├─ Dockerfile            可选容器部署
├─ compose.yaml          本机容器启动配置
└─ README.md             本说明
```

启动后生成的 `.venv` 是本机运行环境。实验数据库与上传数据属于本地运行数据；迁移或分享项目时，请根据需要备份，避免将私有行情一并发出。

## 7. 这个版本的边界

- **训练是真实的，默认行情是合成的。** 合成数据上的指标主要验证流程，不能外推到真实市场。
- **上涨分数没有做概率校准。** 0.60 不能解释为“下一次交易有 60% 的真实获利保证”。
- **最新预测使用训练段拟合的模型。** 这样它与本次留出集研究使用同一个模型；页面显示训练截止日期。它不是自动用全部历史重训的线上预测模型。
- **基准不是买入并持有。** 基准每天开盘买入、收盘卖出，使用同样的双边成本。
- **回测假设不覆盖完整交易规则。** 没有模拟 T+1、停牌、涨跌停、竞价成交、最小交易单位、盘口冲击或实际税费。当前日内执行假设不适合直接用于 A 股普通股票现货。
- **本地单用户应用。** 默认只监听 `127.0.0.1`；使用单线程后台训练队列，没有多用户鉴权、分布式调度或券商接入。上线前需要另行工程化。

项目价值在于展示“数据 → 特征 → 模型 → 时间顺序评估 → 可追溯研究结果”的完整实现。不要把演示结果描述为经过验证的投资能力。

# 数据与回测说明

## 1. 内置数据的性质

| 标识 | 虚构名称 | 数据生成种子 | 演示特点 |
| --- | --- | --- | --- |
| `DEMO.A` | 星河科技 | 41 | 含弱正向滞后动量 |
| `DEMO.B` | 远山能源 | 137 | 波动较大，含弱反向滞后关系 |
| `DEMO.C` | 海蓝消费 | 701 | 波动相对较低，含弱正向滞后关系 |

数据由随机波动、缓慢变化的环境、前一日日内收益和量能项生成。它们**不对应任何真实证券、真实报价或实际业绩**。固定种子让相同参数下的生成结果可复现；模型能够学习到某些生成关系，也不能据此说明真实市场可预测。

默认行情截止于 **2026-10-21**，日期按工作日生成，没有使用真实证券交易所节假日日历。打开页面时不会自动刷新到当日行情。

## 2. CSV 格式与校验

编码为 UTF-8（可带 BOM）或 GB18030，英文逗号分隔，必须包含：

| 字段 | 类型 | 规则 |
| --- | --- | --- |
| `date` | 日期 | 严格 `YYYY-MM-DD`；不能重复、为空或带时分秒 |
| `open` | 数值 | 大于 0 |
| `high` | 数值 | 大于 0，且不小于 open、close、low |
| `low` | 数值 | 大于 0，且不大于 open、close、high |
| `close` | 数值 | 大于 0 |
| `volume` | 数值 | 大于或等于 0，单位在文件内保持一致 |

限制为 **300–20,000 行、文件不超过 8 MB**。导入会规范化列名大小写和前后空格，按日期升序排列；不会自动填补价格、删除坏行或补齐交易日。

每个文件只能有一个标的。若存在 `symbol`、`ticker`、`code`、`ts_code`、`证券代码` 或 `股票代码` 列，服务会拒绝其中包含多个不同标识的文件。若混合数据没有标的字段，程序无法可靠识别，因此仍需导入者核对来源。

### 从真实数据源导入前

1. 确认数据来源允许当前用途。
2. 导出单标的完整日线，不要把分钟线直接改列名当成日线。
3. 统一开、高、低、收的复权口径；不要只对收盘价做复权。
4. 记录股票代码、市场、时区、下载日期和复权方式。
5. 核对停牌、缺失交易日和异常价量，避免将“下一条记录”误解为连续的下一交易日。

仅通过文件结构校验不意味着行情质量、可交易性或复权口径已经正确。

## 3. 信号与成交假设

第 t 天收盘后使用 `X_t` 生成上涨分数 `p_t`：

```text
当 p_t >= threshold：下一条日线开盘投入全部资金，收盘全部退出
当 p_t < threshold：  下一条日线保持现金
```

默认 `threshold = 0.55`。没有做空、杠杆、隔夜仓位或仓位分级。模型输出的 `BUY` 与 `WAIT` 是研究信号标签；系统不会发送实际交易订单。

回归输出不用于决定是否下单，也不是对价格的精确报价。图中最近价格只展示最近 250 条数据，研究计算仍使用整个有效输入范围。

## 4. 手续费和滑点公式

设当日原始日内收益 `r = close / open - 1`，每边手续费比例 `f = cost_bps / 10000`，每边滑点比例 `s = slippage_bps / 10000`。

```text
买入成交价格 = open × (1 + s)
卖出成交价格 = close × (1 - s)

交易日净收益 = (1 + r) × (1 - s) × (1 - f)
               / [(1 + s) × (1 + f)] - 1

现金日净收益 = 0
```

这是将所有资金连同买入费用一起分配、允许碎股的近似账户模型。默认每边手续费 5 bps、滑点 2 bps，一次往返成本约 14 bps；精确结果按上面的乘除公式计算，而非简单减去固定 0.14%。

未包含最低佣金、各市场具体税费、最小交易单位、价格档位、盘口冲击、参与率限制或成交失败。滑点是固定比例假设，不是从盘口数据估计的真实成交偏差。

## 5. 净值、基准与回撤

初始资金默认 100,000，现金不计利息，逐日复利：

```text
equity_d = equity_(d-1) × (1 + net_return_d)
total_return = 最后净值 / 初始资金 - 1
drawdown_d = equity_d / max(初始资金, equity_1, ..., equity_d) - 1
max_drawdown = min(drawdown_d)
```

最大回撤以负数显示，例如 `-8%` 表示相对于此前峰值最多下跌 8%。峰值包含初始资金，因此第一天亏损也会计入回撤。

**基准是每天开盘买入、当天收盘卖出**，每次支付与策略相同的双边手续费和滑点。它不包含隔夜涨跌，因此不是买入并持有。这样可以在同一种日内执行假设下比较模型择时与持续参与的差别。

## 6. 指标解释

| 指标 | 口径 | 注意点 |
| --- | --- | --- |
| 方向准确率 `accuracy` | 测试集中方向判断正确的比例，分类阈值固定 0.5 | 与交易阈值 0.55 独立 |
| 精确率 `precision` | 预测上涨样本中实际上涨的比例，阈值 0.5 | 不等于扣费后的交易胜率 |
| 召回率 `recall` | 实际上涨样本中预测上涨的比例，阈值 0.5 | 只描述分类行为 |
| AUC | 正负方向的分数排序表现 | 测试段只有一种标签时为空 |
| 收益 MAE | `mean(abs(predicted_return - actual_return))` | 单位为收益比例，不是价格误差 |
| 策略总收益 | 测试期末净值 / 初始资金 − 1 | 已包含设置的成本 |
| 年化收益 | `(期末净值 / 初始资金)^(252 / 测试天数) - 1` | 短样本年化可能被明显放大 |
| 最大回撤 | 测试期相对历史峰值的最小回撤值 | 负数，包含初始资金基准 |
| 夏普比率 | `mean(日净收益) / sample_std(日净收益) × sqrt(252)` | 无风险利率设 0；现金日也纳入 |
| 交易胜率 `win_rate` | 实际参与的交易中，扣费后收益大于 0 的比例 | 无交易时为 0，不能理解为失败率 100% |
| 交易次数 `trades` | 测试期参与日数 | 每个参与日完成一次买卖 |
| 参与比例 `exposure` | 参与日数 / 测试期日数 | 是日数比例，不是连续时间仓位占用率 |

若没有波动，夏普比率按实现约定为 0。精确率或召回率的分母为 0 时也显示 0。年化值若超出数值可表示范围会显示为空并附说明。不要只挑选某个好看的指标判断模型价值。

## 7. 与 A 股 T+1 的关系

当前“开盘买入、同日收盘卖出”的假设不能直接用于 A 股普通股票现货。上交所交易规则要求证券在交收前不得卖出，实行回转交易的品种另列例外；普通股票不能因此被当作任意日内回转交易品种。[上海证券交易所交易规则（2026 年修订），3.1.4–3.1.5](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)

导入 A 股历史数据可以研究日内收益的统计关系，但这不代表该回测策略可直接执行。适配需同时修改目标持有期、标签、边界隔离、持仓及资金占用、涨跌停、停牌、交易日历和实际成本。具体市场与品种应使用相应规则，不能因为某类产品允许当日回转就推广到全部股票。

## 8. 如何正确描述一份结果

推荐写法：

> 在某份数据、某段训练和留出区间、固定模型配置下，使用下一日开盘至收盘的日内执行假设及指定成本，得到报告所示的历史结果。输入来源、日期范围、数据摘要、参数和训练截止日期均随报告保存。

避免写法：

- “模型准确率达到某值，所以未来稳定盈利。”
- “合成行情回测很好，所以已经验证真实市场有效。”
- “把多个测试配置中收益最高的那个当作独立样本外结果。”

更可靠的下一步是明确真实数据来源和市场规则，再进行按时间滚动的研究与独立留出评估。
